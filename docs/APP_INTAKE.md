# Four-answer app intake

For a future project, collect only these four answers before deriving contracts:

1. Name: app slug and exact owner/repository.
2. Purpose/sensitivity: useful outcome, users and whether data is public,
   personal, work or sensitive.
3. Selected hosting/build target: NONE or an explicitly selected provider and
   delivery path (Pages, Workers, Amplify Hosting and CodeBuild are distinct).
4. Budget/authorization: spend ceiling, exact allowed operations and stop gates.

M7 answers: aws-factory-pilot / kcloud1/aws-factory-pilot; personal public fictional
inventory and cloud-tooling proof; target NONE; no credentials, provider calls,
resources or spend. Core software install and repository PR are authorized by
Issue #1. Shared-factory profiles are optional, never inherited deployment
permission. Unknown answers require the smallest material clarification.
